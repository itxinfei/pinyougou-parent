## 🐛 常见问题

### Q1: 服务启动失败

**检查**:
- ✅ 配置文件是否正确
- ✅ 端口是否被占用
- ✅ 依赖服务是否启动

**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :9001

# 查看日志
tail -f logs/xxx.log
```

### Q2: 数据库连接失败

**检查**:
- ✅ MySQL 是否启动
- ✅ 用户名密码是否正确
- ✅ 数据库是否存在

### Q3: Redis 连接失败

**检查**:
```bash
redis-cli ping
# 应该返回 PONG
```

### Q4: Dubbo 注册失败

**检查**:
- ✅ Zookeeper 是否启动
- ✅ dubbo.properties 配置是否正确
- ✅ 网络是否通畅
