## 📝 完整的测试流程

### 前置条件

在运行任何测试之前，必须完成以下步骤：

#### 1. 启动基础设施服务

**必须按顺序启动：**

```bash
# 1. MySQL (默认端口 3306)
# Windows:
net start MySQL80
# macOS/Linux:
sudo systemctl start mysql

# 2. Redis (默认端口 6379)
# Windows:
redis-server
# macOS:
brew services start redis
# Linux:
sudo systemctl start redis

# 3. Zookeeper (默认端口 2181)
# 进入 Zookeeper 目录
zkServer.sh start

# 4. Solr (默认端口 8983)
# 进入 Solr 目录
solr start

# 5. ActiveMQ (默认端口 61616)
# 进入 ActiveMQ bin 目录
activemq start
```

**验证基础设施：**
```bash
# 运行基础设施检查脚本
bash scripts/test-infrastructure.sh

# 预期输出：
# ✓ MySQL: 通过
# ✓ Redis: 通过
# ✓ Zookeeper: 通过
# ✓ Solr: 通过
# ✓ ActiveMQ: 通过
```

#### 2. 导入数据库

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS pinyougoudb DEFAULT CHARACTER SET utf8;"

# 导入数据库脚本
mysql -u root -p pinyougoudb < docs/pinyougoudb-v1.3.sql

# 验证
mysql -u root -p -e "USE pinyougoudb; SHOW TABLES;"
# 应该看到 23 张表
```

#### 3. 编译项目

```bash
# 编译所有模块
mvn clean compile -DskipTests

# 安装到本地仓库
mvn clean install -DskipTests
```

#### 4. 启动 Service 层（Dubbo 服务提供者）

**按顺序启动：**

```bash
# 方式一：使用 IntelliJ IDEA（推荐）
# 1. 打开 pinyougou-sellergoods-service 模块
# 2. 找到 Application 启动类
# 3. 右键 → Run 'Application'
# 4. 等待控制台输出 "Dubbo服务启动成功"
# 5. 启动下一个服务...

# 方式二：使用 Maven
mvn spring-boot:run -pl pinyougou-sellergoods-service
mvn spring-boot:run -pl pinyougou-user-service
mvn spring-boot:run -pl pinyougou-content-service
mvn spring-boot:run -pl pinyougou-cart-service
mvn spring-boot:run -pl pinyougou-order-service
mvn spring-boot:run -pl pinyougou-search-service
mvn spring-boot:run -pl pinyougou-page-service
mvn spring-boot:run -pl pinyougou-pay-service
mvn spring-boot:run -pl pinyougou-seckill-service
```

**启动顺序很重要！**

```
推荐启动顺序：
1. pinyougou-sellergoods-service (9001) - 商品服务
2. pinyougou-user-service (9003) - 用户服务
3. pinyougou-content-service (9002) - 内容服务
4. pinyougou-cart-service (9005) - 购物车服务
5. pinyougou-order-service (9004) - 订单服务
6. pinyougou-search-service (9006) - 搜索服务
7. pinyougou-page-service (9007) - 页面服务
8. pinyougou-pay-service (9008) - 支付服务
9. pinyougou-seckill-service (9009) - 秒杀服务
```

#### 5. 启动 Web 层（Dubbo 服务消费者）

```bash
# 同样按顺序启动
mvn spring-boot:run -pl pinyougou-manager-web
mvn spring-boot:run -pl pinyougou-shop-web
mvn spring-boot:run -pl pinyougou-user-web
mvn spring-boot:run -pl pinyougou-cart-web
mvn spring-boot:run -pl pinyougou-search-web
mvn spring-boot:run -pl pinyougou-portal-web
```

## 🐛 常见问题排查

### Q1: 所有接口返回 404

**原因**: Web 服务未启动或配置错误

**解决**:
```bash
# 检查服务是否启动
ps aux | grep java

# 查看日志
tail -f logs/xxx.log
```

### Q2: 接口返回 500 错误

**原因**:
- 数据库连接失败
- Redis 连接失败
- Dubbo 服务注册失败

**解决**:
```bash
# 检查基础设施
bash scripts/test-infrastructure.sh

# 检查 Dubbo 注册中心
# 访问 http://localhost:8080/dubbo-admin
```

### Q3: 前端页面无法加载

**原因**:
- Web 服务未启动
- 静态资源路径错误
- 端口被占用

**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :9101

# 检查 Web 服务日志
```

### Q4: Dubbo 服务注册失败

**原因**: Zookeeper 未启动或网络不通

**解决**:
```bash
# 检查 Zookeeper
nc -zv 172.168.20.221 2181

# 检查 Dubbo 配置
cat pinyougou-common/src/main/resources/properties/dubbox.properties
```
