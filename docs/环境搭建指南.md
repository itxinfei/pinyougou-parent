## 🚀 安装步骤

### 1️⃣ 安装 JDK

#### Windows

```bash
# 1. 下载 JDK 安装包
https://www.oracle.com/java/technologies/javase-jdk8-downloads.html

# 2. 运行安装程序，按提示安装

# 3. 配置环境变量
# 右键"此电脑" → 属性 → 高级系统设置 → 环境变量

# 添加系统变量
JAVA_HOME=C:\Program Files\Java\jdk1.8.0_xxx
Path=%Path%;%JAVA_HOME%\bin

# 4. 验证安装
java -version
javac -version
```

#### macOS

```bash
# 使用 Homebrew 安装
brew install openjdk@8

# 配置环境变量
echo 'export JAVA_HOME="/usr/local/opt/openjdk@8"' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc

# 验证
java -version
```

#### Linux (Ubuntu/Debian)

```bash
# 安装 OpenJDK
sudo apt update
sudo apt install openjdk-8-jdk

# 验证
java -version
```

---

### 2️⃣ 安装 Maven

#### Windows

```bash
# 1. 下载 Maven
https://maven.apache.org/download.cgi
# 下载: apache-maven-3.8.6-bin.zip

# 2. 解压到目录
C:\apache-maven-3.8.6

# 3. 配置环境变量
MAVEN_HOME=C:\apache-maven-3.8.6
Path=%Path%;%MAVEN_HOME%\bin

# 4. 验证
mvn -version
```

#### macOS/Linux

```bash
# 使用 Homebrew 安装
brew install maven

# 或使用 SDKMAN
curl -s "https://get.sdkman.io" | bash
sdk install maven

# 验证
mvn -version
```

---

### 3️⃣ 安装 MySQL

#### Windows

1. 下载 MySQL Installer: https://dev.mysql.com/downloads/installer/
2. 运行安装程序，选择 "Developer Default"
3. 设置 root 密码
4. 完成安装

#### macOS

```bash
# 使用 Homebrew 安装
brew install mysql@5.7

# 启动 MySQL
brew services start mysql@5.7

# 初始化数据库
mysql_secure_installation
```

#### Linux (Ubuntu/Debian)

```bash
# 安装 MySQL
sudo apt update
sudo apt install mysql-server

# 启动 MySQL
sudo systemctl start mysql
sudo systemctl enable mysql

# 安全配置
sudo mysql_secure_installation
```

---

### 4️⃣ 安装 Redis

#### Windows

1. 下载 Redis for Windows: https://github.com/microsoftarchive/redis/releases
2. 解压到目录
3. 运行 `redis-server.exe`

#### macOS

```bash
brew install redis
brew services start redis
```

#### Linux

```bash
sudo apt update
sudo apt install redis-server
sudo systemctl start redis
```

#### 验证 Redis

```bash
redis-cli ping
# 应返回: PONG
```

---

### 5️⃣ 安装 Solr

#### 所有平台（推荐 Docker）

```bash
# 使用 Docker 快速启动 Solr
docker run -d -p 8983:8983 -p 8984:8984 solr:4.10.4

# 创建 core
docker exec -it <container-id> bin/solr create -c pinyougou -n data_driven_schema_configs
```

#### 手动安装

```bash
# 1. 下载 Solr 4.10.4
https://archive.apache.org/dist/lucene/solr/4.10.4/

# 2. 解压
tar -zxvf solr-4.10.4.tgz

# 3. 启动 Solr
cd solr-4.10.4
java -jar start.jar

# 4. 访问管理后台
http://localhost:8983/solr

# 5. 创建 core: pinyougou
# 在管理后台 → Core Admin → Add Core
# Name: pinyougou
# instanceDir: pinyougou
```

---

### 6️⃣ 安装 ActiveMQ

```bash
# 1. 下载 ActiveMQ
https://activemq.apache.org/components/classic/download/

# 2. 解压
unzip apache-activemq-5.15.16-bin.zip

# 3. 启动 ActiveMQ
cd apache-activemq-5.15.16/bin
./activemq start    # Linux/macOS
activemq.bat start   # Windows

# 4. 访问管理后台
http://localhost:8161/admin
# 默认账号: admin / admin
```

## 📦 导入项目

### 使用 IntelliJ IDEA（推荐）

1. **打开 IntelliJ IDEA**
2. **选择 "Open"**
3. **选择项目根目录** `pinyougou-parent`
4. **等待 Maven 导入完成**
5. **配置 JDK**:
   - File → Project Structure → Project → Project SDK → 选择 JDK 1.8
6. **启用 Maven 自动导入**: Settings → Build → Build Tools → Maven → Importing → 勾选 "Import Maven projects automatically"

### 使用 Eclipse

1. **打开 Eclipse**
2. **File → Import → Maven → Existing Maven Projects**
3. **选择项目根目录**
4. **点击 "Finish"**

## ⚙️ 配置文件说明

### 配置位置

每个 Service 和 Web 模块都有独立的配置文件：

```
pinyougou-*-service/src/main/resources/
├── applicationContext.xml       # Spring 配置
├── spring-*.xml                 # Spring 子配置
├── redis-config.properties      # Redis 配置
├── solr-config.properties       # Solr 配置
├── activemq.xml                 # ActiveMQ 配置
└── log4j.properties             # 日志配置
```

### 统一配置脚本

**强烈建议**: 创建统一的环境配置脚本，一键切换开发/测试/生产环境。

## 🔨 编译项目

```bash
# 完整编译（首次）
mvn clean compile -DskipTests

# 安装到本地仓库
mvn clean install -DskipTests

# 只编译某个模块
mvn clean compile -pl pinyougou-sellergoods-service -am

# 跳过测试并强制更新
mvn clean install -DskipTests -U
```

### 常见编译问题

**问题1**: Could not resolve dependencies

```bash
# 解决方案：清除本地仓库缓存
mvn dependency:purge-local-repository
mvn clean install -U
```

**问题2**: 编码错误

```bash
# 在 pom.xml 中添加编码配置
<properties>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    <project.reporting.outputEncoding>UTF-8</project.reporting.outputEncoding>
</properties>
```

## 🎯 启动项目

### 启动顺序

**重要！必须按顺序启动！**

```
基础设施层:
1. MySQL (默认端口 3306)
2. Redis (默认端口 6379)
3. Solr (默认端口 8983)
4. ActiveMQ (默认端口 61616)

Service 层（Dubbo 服务提供者）:
5. pinyougou-sellergoods-service (9001)
6. pinyougou-user-service (9003)
7. pinyougou-cart-service (9005)
8. pinyougou-order-service (9004)
9. pinyougou-search-service (9006)
10. pinyougou-content-service (9002)
11. pinyougou-page-service (9007)
12. pinyougou-pay-service (9008)
13. pinyougou-seckill-service (9009)

Web 层（Dubbo 服务消费者）:
14. pinyougou-manager-web (9101)
15. pinyougou-shop-web (9106)
16. pinyougou-user-web (9104)
17. pinyougou-cart-web
18. pinyougou-search-web (9105)
19. pinyougou-portal-web (9103)
```

### 在 IDEA 中启动

1. **打开 Service 模块**的 Application 启动类
2. **右键 → Run 'Application'**
3. **等待 Dubbo 注册成功**（控制台看到注册成功日志）
4. **启动下一个服务**
5. **最后启动 Web 模块**

## 🐛 常见问题

### Q1: Maven 下载依赖很慢

**解决方案**:

1. 配置阿里云镜像加速
2. 或使用 VPN

```xml
<!-- settings.xml -->
<mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### Q2: Dubbo 连接 ZooKeeper 失败

**检查清单**:

- ✅ ZooKeeper 是否启动
- ✅ `dubbo-registry.properties` 配置是否正确
- ✅ 防火墙是否开放 2181 端口

### Q3: Redis 连接失败

```bash
# 检查 Redis 是否运行
redis-cli ping

# 检查 Redis 配置
redis-cli config get port
redis-cli config get bind-address
```

### Q4: MySQL 中文乱码

```sql
-- 修改数据库字符集
ALTER DATABASE pinyougoudb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
