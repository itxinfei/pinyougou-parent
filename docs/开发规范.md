## 📝 代码规范

### ☕ Java 代码规范

遵循 **阿里巴巴Java开发手册** 标准。

#### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| **包名** | 全小写 | `com.pinyougou.cart` |
| **类名** | 大驼峰 | `CartServiceImpl` |
| **接口名** | 大驼峰（I前缀可选） | `CartService` |
| **方法名** | 小驼峰 | `findCartList()` |
| **变量名** | 小驼峰 | `cartList` |
| **常量名** | 全大写下划线 | `MAX_RETRY_COUNT` |
| **包名** | 全小写 | `com.pinyougou` |

#### 代码格式

```java
// ✅ 正确示例
if (user != null) {
    // TODO: 实现业务逻辑
}

// ❌ 错误示例
if(user!=null){
    // TODO: 实现业务逻辑

// ✅ 正确的空行使用
public class UserService {
    // 属性
    @Autowired
    private UserMapper userMapper;

    // 方法之间空一行

        return userMapper.selectByPrimaryKey(id);
```

#### 异常处理

```java
// ✅ 推荐：捕获特定异常
try {
    orderService.add(order);
} catch (DuplicateKeyException e) {
    logger.error("订单已存在", e);
    throw new BusinessException("订单已存在");
} catch (Exception e) {
    logger.error("添加订单失败", e);
    throw new SystemException("系统错误，请联系管理员");
}

// ❌ 不推荐：捕获异常不做处理
try {
    orderService.add(order);
} catch (Exception e) {
    // 空catch块
}

// ❌ 不推荐：直接吞掉异常
try {
    orderService.add(order);
} catch (Exception e) {
    e.printStackTrace();
}
```

#### 日志规范

```java
// ✅ 使用 Logger
```

## 🌿 Git 提交规范

遵循 [Conventional Commits](https://www.conventionalcommits.org/) 规范。

### 提交格式

```
<type>(<scope>): <subject>
```

### Type 类型

| Type | 说明 | 示例 |
|------|------|------|
| `feat` | 新功能 | `feat(user): 实现用户登录功能` |
| `fix` | 修复 Bug | `fix(order): 修复订单金额计算错误` |
| `docs` | 文档更新 | `docs: 更新README文档` |
| `style` | 代码格式 | `style: 统一代码缩进` |
| `refactor` | 代码重构 | `refactor(cart): 重构购物车逻辑` |
| `perf` | 性能优化 | `perf(search): 优化搜索查询性能` |
| `test` | 测试相关 | `test(user): 添加用户服务测试` |
| `chore` | 构建/工具 | `chore: 更新Maven依赖` |
| `ci` | CI配置 | `ci: 添加GitHub Actions` |
| `revert` | 回滚 | `revert: 回滚commit abc123` |

### 示例

```bash
# ✅ 好的提交信息
git commit -m "feat(user): 实现JWT Token认证"
git commit -m "fix(order): 修复订单取消时库存未恢复"
git commit -m "docs: 添加环境搭建指南"
git commit -m "refactor(cart): 优化购物车查询性能"

# ❌ 不好的提交信息
git commit -m "更新代码"
git commit -m "fix bug"
git commit -m "asdfgh"
```

### Scope 说明

| Scope | 说明 |
|-------|------|
| `user` | 用户相关模块 |
| `order` | 订单相关模块 |
| `cart` | 购物车模块 |
| `goods` | 商品相关模块 |
| `search` | 搜索模块 |
| `pay` | 支付模块 |
| `seckill` | 秒杀模块 |
| `content` | 内容管理模块 |
| `common` | 公共模块 |
| `docs` | 文档 |
| `build` | 构建脚本 |

## 🗄️ 数据库规范

### 表设计规范

```sql
-- ✅ 表名小写，下划线分隔
CREATE TABLE `tb_order_item` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `order_id` bigint(20) NOT NULL COMMENT '订单ID',
  `item_id` bigint(20) NOT NULL COMMENT '商品SKU ID',
  `title` varchar(200) DEFAULT NULL COMMENT '商品标题',
  `price` decimal(20,2) DEFAULT NULL COMMENT '单价',
  `num` int(10) DEFAULT NULL COMMENT '数量',
  `total_fee` decimal(20,2) DEFAULT NULL COMMENT '总金额',
  PRIMARY KEY (`id`),
  KEY `order_id` (`order_id`),
  KEY `item_id` (`item_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COMMENT='订单项表';
```

### 字段规范

- ✅ 字段名小写，下划线分隔
- ✅ 主键统一为 `id` 或 `表名_id`
- ✅ 金额使用 `decimal(20,2)`
- ✅ 时间使用 `datetime`
- ✅ 状态使用 `varchar(1)` 或 `int(1)`
- ✅ 必须添加注释

### 索引规范

- ✅ 主键自动创建索引
- ✅ 外键字段必须加索引
- ✅ 经常查询的字段加索引
- ❌ 索引数量控制在 5 个以内

## 🔧 开发最佳实践

### Service 层规范

```java
@Service
public class OrderServiceImpl implements OrderService {

    private static final Logger logger = Logger.getLogger(OrderServiceImpl.class);

    @Autowired
    private TbOrderMapper orderMapper;

    /**
     * 新增订单
     *
     * @param order 订单对象
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void add(TbOrder order) {
        try {
            // 1. 参数校验
            if (order == null) {
                throw new BusinessException("订单不能为空");
            }

            // 2. 业务逻辑
            order.setCreateTime(new Date());
            orderMapper.insert(order);

            // 3. 日志记录
            logger.info("订单创建成功: " + order.getOrderId());

        } catch (BusinessException e) {
            logger.error("订单创建失败", e);
            throw e;
        } catch (Exception e) {
            logger.error("订单创建异常", e);
            throw new SystemException("系统错误");
        }
    }
}
```

### Controller 层规范

```java
@RestController
@RequestMapping("/order")
public class OrderController {

    private static final Logger logger = Logger.getLogger(OrderController.class);

    @Reference
    private OrderService orderService;

    /**
     * 新增订单
     *
     * @param order 订单信息
     * @return 操作结果
     */
    @RequestMapping("/add")
    public Result add(@RequestBody TbOrder order) {
        try {
            orderService.add(order);
            return new Result(true, "订单创建成功");
        } catch (BusinessException e) {
            return new Result(false, e.getMessage());
        } catch (Exception e) {
            logger.error("订单创建失败", e);
            return new Result(false, "系统错误，请联系管理员");
        }
    }
}
```

## ✅ 代码检查清单

在提交代码前，请检查以下项目：

- [ ] 代码可以正常编译
- [ ] 没有 `System.out.println`
- [ ] 没有 `e.printStackTrace()`
- [ ] 没有空 catch 块
- [ ] 所有方法都有注释
- [ ] 遵循命名规范
- [ ] 没有硬编码密码
- [ ] 使用了参数校验
- [ ] 异常处理正确
- [ ] 日志级别正确
- [ ] 单元测试通过（如果有）
