# 数据库设计说明

本文档介绍品优购项目的数据库设计，包含 23 张表的结构说明和关系图。

---

## 📊 数据库概览

- **数据库名**: `pinyougoudb`
- **字符集**: UTF-8
- **表数量**: 23 张
- **版本**: v1.3

---

## 🗂️ 表结构分类

### 👤 用户管理模块（2 张）

#### tb_user - 用户表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | bigint(20) | 主键，自增 |
| username | varchar(50) | 用户名（唯一） |
| password | varchar(32) | 密码（MD5加密） |
| phone | varchar(20) | 手机号 |
| email | varchar(50) | 邮箱 |
| nick_name | varchar(50) | 昵称 |
| name | varchar(50) | 真实姓名 |
| status | varchar(1) | 状态（Y=正常，N=禁用） |
| head_pic | varchar(150) | 头像地址 |
| source_type | varchar(1) | 来源（1=PC，2=H5，3=Android，4=iOS） |
| created | datetime | 创建时间 |
| updated | datetime | 更新时间 |

**索引**:
- `username` (唯一索引)
- `phone` (普通索引)

#### tb_address - 用户地址表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | bigint(20) | 主键，自增 |
| user_id | varchar(50) | 用户ID |
| province_id | varchar(10) | 省份ID |
| city_id | varchar(10) | 城市ID |
| town_id | varchar(10) | 区/县ID |
| mobile | varchar(255) | 手机号 |
| address | varchar(255) | 详细地址 |
| contact | varchar(255) | 联系人 |
| is_default | varchar(1) | 是否默认（1=是，0=否） |
| notes | varchar(255) | 备注 |
| create_date | datetime | 创建时间 |
| alias | varchar(50) | 地址别名 |

| buyer_nick | varchar(100) | 买家昵称 |
| buyer_rate | varchar(1) | 买家评价状态 |

**订单状态说明**:
- `1` - 未付款（TRADE_NO_PAY）
- `2` - 已付款（TRADE_SUCCESS）
- `3` - 已发货（TRADE_CONSIGN）
- `4` - 已收货（TRADE_FINISHED）
- `5` - 已关闭（TRADE_CLOSED）
- `6` - 已取消（TRADE_CANCEL）

## 🔗 表关系图

```
用户 (tb_user)
  ├─ 1:N → 收货地址 (tb_address)
  └─ 1:N → 订单 (tb_order)

商品分类 (tb_item_cat)
  ├─ 1:N → 商品SPU (tb_goods)
  └─ 1:N → 商品SKU (tb_item)

品牌 (tb_brand)
  └─ 1:N → 商品SPU (tb_goods)

商家 (tb_seller)
  ├─ 1:N → 商品SPU (tb_goods)
  └─ 1:N → 商品SKU (tb_item)

商品SPU (tb_goods)
  ├─ 1:1 → 商品详情 (tb_goods_desc)
  ├─ 1:N → 商品SKU (tb_item)
  └─ 1:N → 订单项 (tb_order_item)

商品SKU (tb_item)
  └─ 1:N → 订单项 (tb_order_item)

订单 (tb_order)
  ├─ 1:N → 订单项 (tb_order_item)
  ├─ 1:1 → 退款记录 (tb_refund)
  └─ 1:1 → 支付日志 (tb_pay_log)

秒杀商品 (tb_seckill_goods)
  └─ 1:N → 秒杀订单 (tb_seckill_order)

广告分类 (tb_content_category)
  └─ 1:N → 广告内容 (tb_content)
```

## 🔧 数据库维护

### 查看表结构

```sql
-- 查看所有表
SHOW TABLES;

-- 查看表结构
DESC tb_order;
-- 或
SHOW COLUMNS FROM tb_order;

-- 查看建表语句
SHOW CREATE TABLE tb_order;
```

### 备份数据库

```bash
# 备份整个数据库
mysqldump -u root -p pinyougoudb > pinyougoudb_backup.sql

# 备份特定表
mysqldump -u root -p pinyougoudb tb_user tb_order > tables_backup.sql
```

### 恢复数据库

```bash
# 恢复数据库
mysql -u root -p pinyougoudb < pinyougoudb_backup.sql
```
